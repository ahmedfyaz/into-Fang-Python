
# 🚀 INTO FAANG – Python Projects (Day 1 & Day 2)

Welcome to my early progress in the **INTO FAANG** journey — where I'm learning AI and building real projects until I land a role at **FAANG** or another top-tier tech company.

This repository contains the first 6 beginner-to-intermediate Python projects I've built as part of my self-taught path into AI and software engineering.

---

## 📦 Projects Included

### 🎯 Day 1

1. **Number Guessing Game**  
   A simple terminal-based game where the user guesses a random number between 1 and 10.

2. **Rock, Paper, Scissors**  
   Classic RPS game where the player competes against the computer with randomized choices.

3. **Quiz Game**  
   A basic text-based quiz to test the user’s general knowledge about computers.

---

### 🧠 Day 2

4. **Password Manager (with Encryption)**  
   A password storage system using the `cryptography` library.  
   🔐 Passwords are encrypted and decrypted using a master key.

5. **Pig Dice Game (Multiplayer)**  
   A logic-based dice game for 2 to 4 players, using a risk/reward mechanic. First to 50 wins.

6. **Text-Based Adventure Game**  
   An interactive storyline game that branches based on user input. Great for learning decision trees and basic logic.

---

## 🧰 Technologies Used

- Python 3.x  
- Cryptography (`Fernet`) for encryption  
- Random module for game logic  
- Simple file I/O and user input handling
